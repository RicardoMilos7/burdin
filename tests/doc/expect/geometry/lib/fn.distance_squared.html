fn distance_squared(a: Point, b: Point): i32

Returns the squared distance between two points.

This is cheaper than a distance because it needs no square root.

Errors

It never fails. Circle.new is the call that can, with GeometryError.NegativeRadius.

let d = distance_squared(Point { x: 0, y: 0, tag: 0 }, Point { x: 3, y: 4, tag: 0 })
assert_eq(d, 25)
