# Reviewed Rust dependencies of the Burdin compiler (issue #449).
#
# One line per external crate in Cargo.lock: name, version, license expression, and why the compiler
# needs it. tests/check_deps.py fails when Cargo.lock and this file disagree, when a license is outside
# the policy below, when Cargo.lock is missing or a crate has no checksum, or when a direct dependency
# in a Cargo.toml is not pinned to an exact version. Every CI job runs that script after `cargo build`,
# with BURDIN_DEPS_REQUIRE_METADATA=1, so the license strings are also re-read from the crates'
# own metadata rather than trusted from this file.
#
# License policy: permissive licenses only. Every identifier in an expression must be one of
#   MIT, MIT-0, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, 0BSD, Zlib, BSL-1.0, Unlicense,
#   CC0-1.0, Unicode-3.0, Unicode-DFS-2016
# or the exact term `Apache-2.0 WITH LLVM-exception`. Copyleft licenses (GPL, LGPL, AGPL, MPL, EPL,
# ...) and identifiers the script does not know fail the check. Because every identifier must be
# allowed, an expression such as `MIT OR GPL-2.0-only` is rejected rather than accepted through MIT.
#
# The compiler has three direct external dependencies: inkwell, which wraps LLVM 21; clap, which declares
# the `burdin` command tree and renders its help (builder API only: clap -> clap_builder -> anstyle,
# clap_lex, strsim); and libc, whose
# `struct stat` and `struct dirent` layouts the generated runtime reads for the directory and metadata
# operations (issue #411) and whose `dlopen` and `dlsym` load libclang when `burdin bindgen` runs (issue
# #245). Everything else comes through inkwell: inkwell -> llvm-sys -> (build) anyhow,
# cc, lazy_static, regex-lite, semver; cc -> find-msvc-tools, shlex; inkwell_internals -> proc-macro2,
# quote, syn; thiserror -> thiserror-impl; and the macro plumbing -> unicode-ident.
#
# LLVM itself is not a Rust crate and is not in Cargo.lock: the build links the system LLVM 21 shared
# library. LLVM is licensed Apache-2.0 WITH LLVM-exception, and the driver reports the linked version
# in `burdin --version`. See docs/dependencies.md.
#
# To update after a deliberate dependency change: set the exact version in Cargo.toml, let
# `cargo build` update Cargo.lock, review the new crate, then add or change its line here and run
# tests/check_deps.py.
#
