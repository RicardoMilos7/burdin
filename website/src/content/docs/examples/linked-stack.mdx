A stack built from nodes, where each node holds the rest of the stack in a `Heap`. `push` and `pop` take the stack by value (`own self`), so the old stack cannot be used after the change.

## What to notice

- `Stack<T>` is generic, and the recursive part is a `Heap<Stack<T>>`. Without the `Heap`, the type would contain itself and have no size.
- `own value: T` takes the value into the stack. A borrowed parameter could not be stored, and the compiler says so.
- `match rest.pop()` moves the rest of the stack out of the popped node. See [ownership](/guide/ownership/) and [generics](/guide/generics-and-interfaces/).
