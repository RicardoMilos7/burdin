## What to notice

- `read_line()` returns `Ok(Some(line))` for each line, `Ok(None)` at the end, and an error if reading fails. The loop handles all three.
- `bump(mut counts, word)` takes the word with `own`, so the map can keep it. A borrowed word could not be stored.
- A map has no order, so the program copies the keys into a `List`, sorts it, and then looks each count up.

The source is in the repository at [`website/examples/word-count.bd`](https://github.com/RicardoMilos7/burdin/blob/main/website/examples/word-count.bd). The checker compares its output with the compiler every time the site is checked.
