## What to notice

- `results.clone()` makes another handle to the same channel, so each task has its own sender.
- The task's closure takes `part` and `out` by move. Each iteration makes its own copies, so each task gets its own values.
- `recv()` waits until a value is available, and `join()` waits for a task to finish. See [concurrency](/guide/concurrency/).
