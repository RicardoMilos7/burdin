## What to notice

- `Circle: Shape { ... }` says the type implements the interface. Nothing else makes the methods available on `Circle`.
- `describe<T: Shape>` is compiled once for each type it is called with. `List<any Shape>` stores each value in a heap box and calls through the interface at run time.
- `{shape.area():.2}` is a format specifier with two digits after the point. See [strings and formatting](/guide/strings-and-formatting/).

The source is in the repository at [`website/examples/shapes.bd`](https://github.com/RicardoMilos7/burdin/blob/main/website/examples/shapes.bd). The checker compares its output with the compiler every time the site is checked.
