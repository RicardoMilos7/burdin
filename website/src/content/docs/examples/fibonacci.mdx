## What to notice

- Integer types are written where they matter. The bound `last` is a `u32`, so the range `0..=last` gives `u32` values, and `fib_loop(n)` takes a `u32` without a cast.
- `fib_loop(90)` fits in a `u64`. A larger input overflows it: in a debug build that is a panic, not a silent wrap. See [basics](/guide/basics/).
- `for _ in 0..n` repeats `n` times without naming the counter.

The source is in the repository at [`website/examples/fibonacci.bd`](https://github.com/RicardoMilos7/burdin/blob/main/website/examples/fibonacci.bd). The checker compares its output with the compiler every time the site is checked.
