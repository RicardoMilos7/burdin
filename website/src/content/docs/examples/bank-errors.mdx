## What to notice

- `Insufficient { needed: i32, available: i32 }` has a message that names both fields, so the refusal explains itself.
- `Parse(ParseIntError) from ...` lets `?` turn a parse failure into a `BankError` without a `match`. `transfer` uses it on its first line.
- `fn main(): Result<()>` returns the last error. The program prints it to standard error and exits with status 1, which is what the expected status file records.
- `mut self` on `withdraw` and `transfer` changes the ledger in place, and the caller writes `ledger.transfer(...)` on a `let mut` binding. See [ownership](/guide/ownership/).
