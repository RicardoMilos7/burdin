## What to notice

- `error enum CalcError` declares the messages once. Printing an error prints its message, so the loop in `main` only writes `{e}`.
- `let Option.Some(b) = stack.pop() else { return Result.Err(...) }` takes the value, or leaves the function with an error. See [control flow](/guide/control-flow/).
- `apply(op, a, b)?` passes a failed division up to `evaluate`, which returns it to its caller. See [errors](/guide/errors/).
- `match token` handles both kinds of token. The compiler checks that the match covers `Num` and `Op`.

The source is in the repository at [`website/examples/rpn-calculator.bd`](https://github.com/RicardoMilos7/burdin/blob/main/website/examples/rpn-calculator.bd). The checker compares its output with the compiler every time the site is checked.
