Each example is a complete program. The source and its output come from the same files the compiler checks, so what you see here is what `burdin run` prints.

<Aside type="tip" title="Every example is checked">
	When the site is built, each example is compiled and run, and its output is compared with the stored result. An
	example whose output drifts from the compiler fails the build, so the examples stay correct as the language changes.
</Aside>

To run one, save the program as `main.bd` and run it:

```text
burdin run main.bd
```
